# Severity Levels

## CRITICAL

Immediate production risk.

Examples:

- Authentication bypass
- Remote code execution
- Data loss
- Privilege escalation

## HIGH

Serious production issue.

Examples:

- Security vulnerabilities
- Broken business logic
- Data corruption

## MEDIUM

Moderate risk.

Examples:

- Reliability issues
- Performance bottlenecks
- Missing validation

## LOW

Minor issues.

Examples:

- Readability
- Maintainability
- Style inconsistencies
