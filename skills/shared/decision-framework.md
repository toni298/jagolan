# Decision Framework

Use this when comparing technical options.

## Evaluation Criteria

- correctness
- security
- reliability
- performance
- maintainability
- simplicity
- scalability
- cost
- team familiarity
- operational complexity
- vendor lock-in
- reversibility
- time to deliver
- migration path

## Decision Output

For important decisions, include:

1. Context
2. Options considered
3. Recommended option
4. Why this option
5. Tradeoffs
6. Risks
7. Mitigations
8. Reversal or migration plan

## Rule

Do not claim one technology or architecture is universally best.
Tie decisions to context.
